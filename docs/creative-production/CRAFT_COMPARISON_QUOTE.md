# Original craft components: ContrastComparison and EditorialQuote

Requirement: MW05-E05-03 (component library). Scope: two new
bounded original editable composition layouts. Status: PARTIAL until
the exact-source CI evidence and independent human creative review.

## Purpose, truth and rights

ContrastComparison displays two authored conceptual states with equal
visual authority, a separator and a persistent not-measured-evidence
disclosure. It does not calculate an improvement, draw invented statistics,
synthesize before/after imagery, or imply an independently observed outcome.

EditorialQuote lays out illustrative editorial copy, context and an
authored small publisher mark. Its bound notice explicitly says the quote's
attribution is not verified. It is not a real testimonial, endorsement
or source-rights certification. Actual attributable quotes require a
separate provenance/permission contract.

Both are source-owned graphics, not customer software captures or stock
footage. There is no arbitrary scripting, shader, texture source or
unreviewed third-party media. The user remains responsible for the truth
and publication rights of their own written copy.

## Editable component contract

Both are additional closed HeroLayout variants in the existing ProductHero
instance and use the canonical UpsertProductHero change, existing project
CAS, Semwright Native SDK and Motion Canvas Film adapter.

Six persistent Canvas object roles remain unchanged across families and
output aspects: eyebrow, headline, body, wordmark, rule and disclosure.
The contrast uses a vertical split at 16:9 and a horizontal divider on
compact formats; the editorial quote uses a horizontal signature rule.

The stable versioned source UUIDs, normal Canvas style, transform and
Y/opacity entrance keyframes stay editable. The two new layouts use explicit
geometry for 1920x1080, 1080x1920 and 1080x1080 with source-bounded text.
Long words, overflowing text boxes and out-of-safe-area nodes are rejected
rather than clipped or silently resized. The source is never baked as a
fake screenshot.

The existing three-way component update retains non-conflicting human
styles and independent text while rejecting ambiguous overwrites and
property locks. The camera and unrelated scene fields remain owned by
the project. Detach keeps all Canvas objects.

Attached disclosure text is mandatory. A user cannot delete or replace
the bound notice with claims of verified results or endorsements via
project changes or the Studio client. Detach explicitly removes that
component ownership first; ordinary Canvas editing may then continue.

## Acceptance and current limits

Rust/TypeScript parity and source tests validate deterministic roles,
stable IDs across three aspect ratios, actual separator geometry, semantic
disclosures, serializability, camera and human-style retention, conflict
refusal and reduced-motion counterparts.

Native Film contract tests assert five actual fixed text-container
subjects, six semantic parent nodes, exact cubic-out entrance motion,
a 180-frame composition and real text-line content.

A dedicated pinned Semwright Broker / Motion Canvas / MLT CI workflow
renders two real H.264/AAC masters, original editable source layouts,
contact sheets and decoded-media evidence. It independently checks
frame occupancy against source geometry, frame-to-frame motion, settled
stability, an exact project SHA, and bundle generation rotation.
These are technical tests, not automated aesthetic approval.

The new workflow and all broad CI checks must be green for the exact PR
head SHA before technical admission. Even a green workflow does not
certify a comparative advantage, testimonial rights, aesthetics or
independent client adoption.

This does not complete the 36-component/eight-family library target.
Unimplemented craft families, additional brand and type controls,
source-authenticated components, formal admitted-versus-draft library
reviews, actual client composition tasks and a human creative pilot
remain required.
